# Pandas基础

Pandas是一个功能强大的结构化数据分析的工具集，底层是基于Numpy构建的，无论是在数据分析领域、还是大数据开发场景中都有显著的优势
核心：DataFrame（类似表格）、Series（类似表格中的一列）

构造DataFrame的主要方式：
``` python
import pandas as pd

df1 = pd.DataFrame([
    {'姓名': '张三', '语文': 85, '数学': 92, '英语': 78},
    {'姓名': '李四', '语文': 78, '数学': 88, '英语': 95},
    {'姓名': '王五', '语文': 92, '数学': 96, '英语': 89}
])

df2 = pd.DataFrame({
    '姓名': ['张三', '李四', '王五'],
    '语文': [85, 78, 92],
    '数学': [92, 88, 96],
    '英语': [78, 95, 89]   # 修正：补全右括号
})

df3 = pd.DataFrame([
    ('张三', 85, 92, 78),
    ('李四', 78, 88, 95),
    ('王五', 92, 96, 89)
], columns=['姓名', '语文', '数学', '英语'])

df4 = pd.DataFrame([
    ['张三', 85, 92, 78],
    ['李四', 78, 88, 95],
    ['王五', 92, 96, 89]
], columns=['姓名', '语文', '数学', '英语'], index=['a', 'b', 'c'])

```

## 数据查看、选择、过滤

常用方法：

| 类别        | 语法                                  | 说明                         |
| --------- | ----------------------------------- | -------------------------- |
| 数据预览      | `df.head(n)`                        | 查看前 n 行数据（默认 5 行）          |
| 数据预览      | `df.tail(n)`                        | 查看末尾 n 行数据（默认 5 行）         |
| 统计描述      | `df.describe()`                     | 对数值列生成统计描述（计数、均值、标准差、分位数等） |
| 数据信息      | `df.info()`                         | 查看列名、非空计数、数据类型及内存占用        |
| 数据维度      | `df.shape`                          | 属性，返回 (行数, 列数) 元组          |
| 列名列表      | `df.columns`                        | 属性，返回所有列名组成的 Index 对象      |
| 单列操作      | `df['列名']` 或 `df.列名`                | 获取单列数据（返回 Series）          |
| 多列操作      | `df[['列1', '列2', ...]]`             | 获取多列数据（返回 DataFrame）       |
| 位置索引切片    | `df.iloc[start:stop:step]`          | 基于整数行号切片，**不含** stop       |
| 标签索引切片    | `df.loc[start:stop:step]`           | 基于索引标签切片，**含** stop        |
| 条件筛选（单条件） | `df[df['销售数量'] >= 10]`              | 筛选销售数量大于等于 10 的行           |
| 条件筛选（单条件） | `df[df['产品类别'].isin(['服装', '食品'])]` | 筛选产品类别属于指定列表的行             |
| 条件筛选（单条件） | `df[df['单价'].between(50, 200)]`     | 筛选单价在 50 到 200 之间的行        |
| 条件筛选（多条件） | `df[(条件1) & (条件2)]`                 | 使用 `&` 表示"并且"，同时满足多个条件     |
| 条件筛选（多条件） | `df[(条件1) \| (条件2)]`                | 使用 `\|` 表示"或者"，满足任意一个条件即可  |
## 数据清洗

数据清洗是指发现并纠正数据中可识别的错误的过程，包括处理缺失值、重复值、异常值，统一数据格式，保证数据的一致性


## 数据排序与分组

在进行数据排序时，有两种排序方式，分别是升序和降序。而基于Pandas进行数据排序时，是可以按照多个列进行排序的

多列排序：进行多个列排序时，会先按照第一列进行排序，第一列的值相同时，才会按照第二列进行排序

数据分组：就是把数据按照某个特征分成不同的组，然后把对每个组分别进行统计计算

|聚合操作|代码示例|说明|
|---|---|---|
|求和|`df.groupby('产品类别')['销售额'].sum()`|计算各组总和|
|计数|`df.groupby('产品类别')['销售额'].count()`|统计各组非空值个数|
|平均值|`df.groupby('产品类别')['销售额'].mean()`|计算各组均值|
|最大值|`df.groupby('产品类别')['销售额'].max()`|找出各组最大值|
|最小值|`df.groupby('产品类别')['销售额'].min()`|找出各组最小值|
|标准差|`df.groupby('产品类别')['销售额'].std()`|计算各组标准差|
|中位数|`df.groupby('产品类别')['销售额'].median()`|计算各组中位数|
